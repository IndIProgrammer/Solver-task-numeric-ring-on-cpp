# Solver-task-numeric-ring-on-cpp
Программа для решения задачи "Числовое кольцо".

<h3 align="left">Задача "Числовое кольцо"</h3>
В кольце записаны N чисел, составляющих по часовой стрелке 3 числа: два слагаемых и сумму. <br>
Требуется написать программу, которая по строке чисел, считая ее кольцом, находит какое-нибудь решение в виде A+B=C.<br>
Все цифры числа должны входить в числа только один раз и в порядке следования в кольце.<br>
Цифр в кольце не более 1000.<br>
Формат входных данных: Входной файл содержит 1 строку, в которой без пробелов перечислены цифры кольца.<br>
Формат выходных данных: В выходной файл выводится тождество в виде <слагаемое1>+<слагаемое2>=<сумма> без пробелов внутри или слово «No», если решения не существует.

<h3 align="left">Как запустить:</h3>
Чтобы запустить программу достаточно скачать файл Числовое кольцо.exe и запустить его на своём устройстве.

<h3 align="left">Пример работы программы</h3>
Пример 1:<br>
(входные данные)<br>
01902021<br>
(выходные данные) 190+20=210<br>
Пример 2:<br>
(входные данные)<br>
111111<br>
(выходные данные)<br>
No
